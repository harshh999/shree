# Shree Ganesh Nursery & Farm

Website for **Shree Ganesh Nursery & Farm**, Bodakdev, Ahmedabad.

## Nursery FAQ Assistant

The website includes a lightweight, completely scripted FAQ assistant located in the bottom-right corner. It features:
- Predefined clickable categories and question/answer trees.
- Direct contact actions: WhatsApp chat ("Talk to our team") and phone dialer ("Call Nursery").
- Client-side React state navigation (no external APIs, no AI key dependencies, and no backend database required).

The FAQ data is organized and editable in [`data/faq.ts`](data/faq.ts).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production Build

```bash
npm run build
npm run start
```
